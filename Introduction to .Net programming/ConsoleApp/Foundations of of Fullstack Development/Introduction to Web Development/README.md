# Basic HTML Exercise

This project was created as part of the Foundations of Full-Stack Development course to practice creating a simple HTML file with proper structure.

It demonstrates:

- The basic structure of an HTML document (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)  
- Linking an external JavaScript file

The JavaScript file currently only logs a message to the console (`console.log("Hello, World!")`) to confirm that it is correctly linked.

## How to Run

1. Open `index.html` in a web browser.  
2. Open the browser console to see the message logged by `script.js`.
