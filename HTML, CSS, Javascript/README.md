# Portfolio & Services Webpage

This project is a personal portfolio webpage built with **HTML, CSS, and JavaScript** to showcase projects, skills, and a contact form.  
It was created as part of the Foundations of Full-Stack Development course to practice structuring modern web pages and adding interactivity.

## Purpose

The purpose of this project was to:

- Learn and practice **HTML structure and semantic elements**.
- Apply **CSS styling and responsive design** using Flexbox, Grid, and media queries.
- Implement **JavaScript interactivity**, including:
  - Hamburger menu toggle for mobile navigation
  - Project filtering by category
  - Lightbox functionality for project images
  - Basic contact form validation
- Understand how to structure a multi-file web project (`index.html`, `styles.css`, `script.js`) and link resources correctly.

This project helped reinforce principles of **accessibility, responsive design, and DOM manipulation**, which are foundational for building interactive full-stack applications.

## Concepts Demonstrated

- Semantic HTML (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`)
- CSS layout techniques (Flexbox, Grid)
- Responsive design using media queries
- JavaScript DOM manipulation and event handling
- Accessibility considerations (ARIA attributes, keyboard navigation)
- Form validation and user feedback
- Componentized project structure with separate HTML, CSS, and JS files
- Lightbox implementation for images

## How It Works

1. **Navigation:**  
   - The hamburger menu toggles the mobile navigation and is fully keyboard-accessible.
2. **Projects Section:**  
   - Filter projects by category using the dropdown menu.
   - Click a project image to open a lightbox with a larger view.
3. **Skills Section:**  
   - Lists technical skills in a responsive grid.
4. **Contact Form:**  
   - Basic validation prevents submission if fields are empty or the email is invalid.
   - Alerts a mock “message sent” upon successful submission.

## How to Run

1. Clone or download the project folder.
2. Open `index.html` in a web browser.
3. Interact with the webpage:
   - Resize the browser window to see responsive behavior.
   - Click the hamburger menu on mobile view.
   - Filter projects or click project images to see the lightbox.
   - Fill in the contact form and submit to test validation.

## Possible Improvements

- Replace mock form submission with a backend service to send actual messages.
- Add animations for project filtering and smooth scrolling.
- Enhance lightbox with captions or slideshow functionality.
- Improve mobile design with more advanced breakpoints or layouts.
- Use a frontend framework (React, Vue) for component-based structure in future projects.

## Notes

This project focuses on **front-end fundamentals** and serves as a preparatory step before implementing full-stack applications with backend integration.  
It demonstrates the principles of clean code, responsive design, accessibility, and interactive user interfaces.
